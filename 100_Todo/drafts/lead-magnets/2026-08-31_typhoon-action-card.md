# 誘餌草稿：沖繩颱風應變卡

用途：接住颱風文的搜尋流量（`okinawa-typhoon-family-travel-guide`，28 天曝光 1,109，站上最大入口）。
現況問題：目前站上唯一誘餌是「沖繩租車證件檢查表」，只對得上兒童安全座椅那一篇。曝光最高的颱風、伴手禮、單軌三篇都沒有對應誘餌。

交付形式：一頁 A4、可列印、可離線看。放在 `/checklist/okinawa-typhoon-action-card`（比照現有檢查表頁，維持 `noindex`）。

## 卡片內容

### 第 0 步：先確認你在哪一個階段

- **還沒出發（剩 3 天以上）** → 看「出發前」
- **還沒出發（剩 3 天以內）** → 看「出發前」＋「聯絡清單」
- **人已經在沖繩** → 直接跳「人在當地」

---

### 出發前：三件事按順序做

**1. 航班（先做這件）**
- [ ] 找**航空公司**，不是機場。機場只公告跑道狀況，改期補位是航空公司決定
- [ ] 查你的票種能不能免費改期；廉航與傳統航空規則不同
- [ ] 記下客服電話與線上改票網址，存進手機離線筆記

**2. 租車**
- [ ] 直接通知租車營業所，不要自己猜能不能延、能不能退
- [ ] 問三件事：航班取消能否免費取消、能否延後取車、營業所颱風天開不開
- [ ] 把回覆截圖存下來

**3. 飯店**
- [ ] 聯絡飯店確認颱風期間的取消政策
- [ ] 訂房平台的「不可退款」方案，遇到颱風不一定自動適用天災條款，要問

---

### 人在當地：先顧孩子的 24 小時

- [ ] **水**：每人每天 2 公升，先買足兩天
- [ ] **孩子的食物**：習慣的零食、沖泡食品、副食品
- [ ] **藥**：常備藥、退燒藥、平常在吃的處方藥
- [ ] **電**：行動電源充飽，手機開省電模式
- [ ] **光**：手電筒或手機手電筒，飯店停電時用
- [ ] **尿布濕紙巾**：算到比預期多一天的量

超市和便利商店會在颱風前一天被清空。要買就前一天早上去，不要等當天。

---

### 不要做的三件事

1. **不要把「雨天備案」直接當颱風備案。** 雨天可以去水族館、美國村；颱風天這些地方會關門，而且路上有飛落物風險。
2. **不要在颱風警報期間開車移動。** 沖繩的強風會影響車輛，租車保險也可能不理賠天災期間的自行移動。
3. **不要等警報解除就立刻去海邊。** 解除後仍有長浪與離岸流，海況恢復比天氣慢。
