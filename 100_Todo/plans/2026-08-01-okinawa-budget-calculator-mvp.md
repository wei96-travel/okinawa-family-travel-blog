# 沖繩親子旅費計算器 MVP

更新日期：2026-08-01

## 目標

做出一個手機優先、免登入、一般家長第一次打開就會使用的沖繩親子旅費估算工具，先本機驗證操作與結果，再公開進行 14 天免費公測。

## 第一版方向

- 成人與兒童人數
- 旅遊天數
- 省錢、一般、舒適三種旅行方式
- 租車或大眾運輸
- 可選填全家來回機票總價
- 顯示總預算區間、每人費用及分類明細
- 產生不含姓名、Email 或個資的分享連結
- 導向既有住宿、租車與票券整理頁

## 不做的功能

- 會員與登入
- 付款與訂閱
- 即時機票、飯店或票券價格
- 多人同步編輯
- 伺服器資料庫
- 自動產生或儲存 PDF

## 驗證

- TypeScript 與 Next.js production build
- 內容稽核
- 375px、768px、1024px 與 1440px 響應式檢查
- 鍵盤操作、標籤、焦點與至少 44px 點擊區
- 分享網址可重建相同輸入條件
- 不產生水平捲動

## 公測門檻

第一版通過本機檢查並經使用者確認後，公開部署並開始 14 天免費公測。公測期間觀察開始、完成、分享、進階版興趣及下一步點擊事件。

## 2026-08-01 驗證結果

- `npm.cmd run content:audit:strict`：46 篇文章、0 個嚴重問題。
- Next.js production build：成功產生 71 個靜態頁面。
- 手機與桌面寬度 375、768、1024、1440px：無水平溢位。
- 分享網址可還原 3 位成人、1 位兒童、7 天、舒適型、大眾運輸與 NT$42,000 機票設定。
- 結果正確顯示 `NT$238,518～NT$272,592`，瀏覽器主控台無錯誤。
- 2026-08-01 使用者同意納入部落格；完成最終檢查後公開部署。計算器維持免費，不會在這次更新中收費。

## 後續功能候選

- 航空類型（待確認使用者指的是「廉航」）：廉航、傳統航空、還不確定。
- 若選廉航，再估算托運行李、選位與機上餐等附加費。
- 第一版先不加入，等免費公測確認有人需要後再做；暫不串接航空公司即時票價。
