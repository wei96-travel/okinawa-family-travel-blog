**「尚未有評價」是頁面載入未完成的暫態，不是真的沒評價。** 本 session 一開始因此誤判小藥袋與雨衣「不通過」，等待評價區渲染完後數字就出現，且與先前 API 取得的數值完全吻合（電子秤 2.4萬 ≈ API 的 24,202；雨衣 7,564 ≈ API 的 7,563）。**API 資料是可靠的，讀商品頁才需要等。**
