# 搜尋訊號帶動內容與分潤成長計畫

更新日期：2026-07-26

## 目標

- 先放大 Google 已經開始曝光的主題，不再平均分配文章產量。
- 住宿內容改成協助讀者比較「地點方便、價格較親民、帶小孩好不好住」。
- 分潤連結保留，但只放在讀者已經準備做決定的位置。
- 商品從真實旅行情境出發，不把文章改成商品清單。

## 選定方向

### 0. 先尊重既有 SEO 實驗

- 每次動舊文章前先讀 `content/seo-scorecard.md`。
- 已改過標題、摘要、網址或主要段落的頁面，在記分卡指定的驗證日前不再修改。
- 安全座椅頁在 2026-07-29 前保持不動，2026-07-30 後先比較 CTR 與平均排名，再決定是否要改。
- 自駕休息點舊網址仍在 301 合併期間，不新增舊網址連結，也不為短期數字反覆改新頁標題。

### 1. 每日內容改成一新一舊

- 一篇新文章：承接下一個明確搜尋問題。
- 一篇舊文優化：只處理已有曝光、點擊不足，而且不在實驗冷卻期的頁面。
- 若適合的舊文都在冷卻期，當天改做內部連結盤點、飯店研究或商品候選核對，不為了湊數硬改標題。
- 不再要求每天兩篇全新文章，避免舊文章累積曝光卻沒被改善。

第一批順序：

1. 安全座椅文章維持觀察，2026-07-30 後才判讀。
2. 研究自駕尿急用品候選，不先放未確認連結。
3. 製作那霸「地點方便、價格較親民」飯店候選表。
4. 製作恩納「親子友善、移動方便」飯店候選表。
5. 等自駕休息點舊網址的 301 訊號逐步合併，再判斷是否改標題。

### 2. 飯店不要寫死「最便宜」

房價會跟日期、房型與人數變動，因此使用以下標準：

- 用「價格較親民」「在同區較容易找到較低總價」取代「最便宜」。
- 每區先挑 3 至 5 間，不做十幾間的大清單。
- 表格欄位固定為：適合情境、交通位置、停車、房型、兒童入住、查詢時價格帶、注意事項。
- 價格只記錄查詢日期與條件，按鈕仍讓讀者查看自己日期的總價。
- 飯店官網核對兒童入住與設施，Trip.com 用於查看日期、房型與即時總價。

### 3. 分潤揭露只出現一次

- 不取消揭露，但縮短成一行，放在第一個分潤按鈕附近。
- 文章開頭先解決問題，不先談分潤。
- 不在每個按鈕旁重複「本站可能獲得分潤」。
- Trip.com 放在住宿與租車決策點；Shopee 放在用品情境段落。
- 所有外部聯盟連結保留 `rel="sponsored noreferrer"` 與 GA4 點擊追蹤。

建議文字：

> 下面部分連結為合作連結；你完成預訂或購買時，本站可能取得分潤，價格不會因此增加。

### 4. 「半路尿急」商品只放真正能補位的類別

優先研究：

- 兒童拋棄式尿袋／凝固型尿袋
- 兒童攜帶式尿壺
- 摺疊旅行便盆與替換袋
- 防水座椅墊
- 小包濕紙巾
- 夾鏈袋或小垃圾袋

文章必須一起說明：

- 先安全停車，不能在車輛行進中使用。
- 商品尺寸、適用年齡、男女使用方式與防漏設計要逐項核對。
- 不能宣稱完全不漏，也不能把商品寫成廁所的日常替代品。
- 主要用途是塞車、偏遠路段或最近廁所仍有距離時的備案。

## Codex 與 Claude Code 分工

### Codex

- 決定文章優先度、搜尋意圖、標題、內部連結與分潤出現位置。
- 撰寫或重寫正式文章。
- 檢查真人口吻、SEO、手機畫面、追蹤與正式站。

### Claude Code

- 先做飯店候選研究表，每區 6 間，附飯店官網與 Trip.com 查詢結果。
- 先做尿急用品候選表，核對商品類別、適用對象、規格與風險。
- 不直接改正式文章，不自行加入聯盟連結，不 commit、不 push。

## 成功判斷

- 兒童安全座椅頁點閱率從約 1.6% 提升到 3% 以上。
- 自駕廁所頁取得第一個 Google 點擊。
- 那霸或恩納住宿頁取得第一個 Google 點擊。
- GA4 能分辨飯店、租車與用品按鈕的外連點擊。
- 分潤內容不超過文章主體的約 20%，且每個商品都能對應一個明確旅行情境。

## 暫時不做

- 不把訂房整理頁改成大量飯店卡片商城。
- 不移除必要的聯盟揭露。
- 不使用「全沖繩最便宜」「一定不漏」「保證適合」等說法。
- 不在沒有核對飯店官網或商品規格前加入正式連結。
