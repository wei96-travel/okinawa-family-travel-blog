# Facebook 獨立長文｜還車前兩小時，最怕的其實不是忘了加油

沖繩最後一天，行李都上車了，導航也設定好租車公司。

看起來只剩加油、還車、去機場，應該很簡單。

但真正容易讓全家手忙腳亂的，通常不是加油站怎麼操作，而是孩子突然想上廁所、最後一袋伴手禮塞不進去，或到了還車場才發現護照還在後車廂最裡面。

回程日和一般行程不一樣。平常晚半小時到景點，頂多少逛一點；還車、接駁和報到時間卻會一路往後推。前面多塞一間店，後面就少一段緩衝。

我會建議先把最後一天縮成「一個主任務」。

想補伴手禮，就選一個停車方便、廁所也比較好找的商場或超市。想吃最後一餐，就不要再同時安排景點和兩間藥妝店。最後一天不是把遺漏的行程全部補回來，而是把人、行李和車順利送到機場。

最後一站也不要只看「離機場近不近」。租車通常要先回營業所，再搭接駁車前往航廈，所以真正該看的，是店家到加油站、還車地點和機場之間有沒有繞路。地圖顯示的車程還沒包含結帳、整理戰利品、加油和等待接駁，這些零碎時間加起來，很容易比原本想得久。

上車前，可以先把東西分成三區。

第一區是還車前不會再用到的托運行李，直接放後車廂深處。

第二區是到機場才會用的隨身行李，護照、手機、充電線、外套和孩子在飛機上的用品都放在固定位置，不要混進購物袋。

第三區則是車上最後兩小時可能會用到的東西：水、少量點心、濕紙巾、替換衣物和垃圾袋。這一袋放在大人伸手拿得到的地方，不必每次都把後車廂重新翻一遍。

接著先處理孩子，再處理車。

準備去加油前，先找一個確定能停車、能上廁所的地方。不要等油加完、時間開始緊了，才問附近哪裡有洗手間。加油站是否有廁所、能不能使用，要看現場設施與規定，不能把它當成唯一備案。

如果兩位大人同行，也可以提前分工。一個人負責加油、收據與還車文件，另一個人負責孩子、隨身包和下車前最後檢查。到了還車場才臨時討論誰拿什麼，最容易漏東西。

最後一次關車門前，我會再看五個地方：

1. 安全座椅旁邊和椅墊縫隙。
2. 前座置物格與車門杯架。
3. 後車廂角落和行李下面。
4. 手機架、充電線與車充。
5. 加油收據、租車文件與護照是否分開收好。

伴手禮少買一袋不會毀掉旅行，少去一個景點也沒關係。最後一天真正舒服的版本，是孩子沒有餓到哭、大人不用拖著行李奔跑，還有時間在機場好好整理一下再登機。

完整的退房、加油、還車和機場時間安排，我放在第一則留言。
