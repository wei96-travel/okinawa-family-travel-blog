# 社群題材狀態與防重複表

最後更新：2026-08-06 22:17

用途：發布前先確認某個題材是「已公開、草稿完成、已排程、已撤回」哪一種狀態。不能只查同一平台，也不能把換成輪播、Reel 或 Threads 當成全新內容。

## 判斷規則

- **已公開**：有公開連結。相同痛點與相同結論不得再次發布。
- **草稿完成**：尚未公開，但已占用這個角度。其他平台若要使用，必須先決定由哪一個版本發布。
- **可延伸**：主題相近，但搜尋問題、讀者情境與主要答案都不同。
- **重複撤回**：即使換平台或換圖片，只要「痛點 + 結論」相同，就停止排程。
- 發布前至少搜尋三組詞：主題名、讀者痛點、文章核心答案；同時查本表、`publishing-master-log.md`、`work/social/` 與 `content/blog/`。
- 只有「同一大主題但解決不同問題」才可跨平台延伸。單純縮短、換標題、換圖片或改成影片，不算新角度。

## 每晚 20:00 防重複門檻

1. 先從當天候選提取「主題、痛點、主要答案」三欄。
2. 對照本表與發布總表，再搜尋 `work/social/` 和 `content/blog/`。
3. 發現相同痛點與相同答案，直接標記「重複撤回」，不靠改標題補救。
4. 只有通過檢查，才製作當晚最終圖片與完整文案預覽。
5. 使用者確認後才能發布；發布成功後立即把永久連結回填發布總表與本表。
